## 六、测试中发现的关键点

1. **版权/敏感内容检测**：第一次 fast 720p 用「古装剑客」prompt 触发了
   `OutputVideoSensitiveContentDetected.PolicyViolation`（疑似版权保护）。
   换成中性 prompt 后成功。→ **漫剧客户若做古装/知名 IP 题材，需在 prompt 层规避敏感词**，
   这也是路由层可以帮客户做的事（自动改写/降敏）。

2. **`resolution` 必须放 `metadata`**：放顶层会被忽略、默认 720p 多花钱（历史踩坑，本次已规避）。

3. **视频自动转存生效**：生成的视频 URL 直接是自有 OSS 地址，客户无需自己处理 24h 失效问题。
